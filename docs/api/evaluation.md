# Evaluation Module

The evaluation module provides comprehensive tools for assessing the performance of the [theorem proving system](models.md#theoremllm), including metrics for proof quality, correctness, and efficiency.

## Components

### ProofEvaluator

Core component for evaluating generated proofs. Works in conjunction with the [SymbolicReasoner](symbolic.md#symbolicreasoner) for verification.

```python
from src.evaluation import ProofEvaluator

evaluator = ProofEvaluator(config)
```

#### Features

- Text similarity metrics
- Proof correctness verification
- Domain-specific evaluation
- Performance analysis

#### Methods

- `evaluate_proof(generated_proof: str, reference_proof: str, theorem: Dict[str, Any]) -> Dict[str, Any]`
  - Evaluates generated proof against reference
  - Returns comprehensive evaluation metrics

- `calculate_metrics(generated_proofs: List[str], reference_proofs: List[str]) -> Dict[str, float]`
  - Calculates batch metrics
  - Returns aggregated scores

- `analyze_errors(proof: str) -> List[Dict[str, Any]]`
  - Analyzes proof for errors
  - Returns detailed error analysis

### MetricsCalculator

Calculates various evaluation metrics for proofs generated by the [TheoremLLM](models.md#theoremllm).

```python
from src.evaluation import MetricsCalculator

calculator = MetricsCalculator(config)
```

#### Methods

- `calculate_bleu(generated: str, reference: str) -> float`
  - Calculates BLEU score
  - Returns score between 0 and 1

- `calculate_rouge(generated: str, reference: str) -> Dict[str, float]`
  - Calculates ROUGE scores
  - Returns dictionary of scores

- `calculate_correctness(proof: str, theorem: Dict[str, Any]) -> Dict[str, Any]`
  - Evaluates proof correctness
  - Returns correctness metrics

## Evaluation Metrics

### Text Similarity Metrics

1. **BLEU Score**
   - N-gram precision
   - Brevity penalty
   - Smoothing methods

2. **ROUGE Scores**
   - ROUGE-1 (unigrams)
   - ROUGE-2 (bigrams)
   - ROUGE-L (longest sequence)
   - ROUGE-W (weighted LCS)

### Proof Quality Metrics

1. **Correctness**
   - Logical validity (via [SymbolicReasoner](symbolic.md#symbolicreasoner))
   - Step completeness
   - Conclusion validity
   - Premise usage

2. **Style**
   - Clarity
   - Conciseness
   - Structure
   - Readability

### Domain-Specific Metrics

Metrics aligned with the [supported mathematical domains](symbolic.md#domain-support):

1. **Algebra**
   - Equation manipulation
   - Variable handling
   - Term simplification

2. **Analysis**
   - Limit arguments
   - Epsilon-delta usage
   - Series convergence

3. **Geometry**
   - Construction validity
   - Angle relationships
   - Distance calculations

4. **Number Theory**
   - Divisibility arguments
   - Modular arithmetic
   - Prime factorization

## Usage Examples

### Basic Evaluation

```python
# Initialize evaluator with configuration
config = {
    'metrics': {
        'text_similarity': {
            'bleu': {'enabled': True, 'weights': [0.25, 0.25, 0.25, 0.25]},
            'rouge': {'enabled': True, 'metrics': ['rouge-1', 'rouge-2', 'rouge-l']}
        },
        'proof_quality': {
            'correctness': {'enabled': True},
            'style': {'enabled': True}
        }
    }
}
evaluator = ProofEvaluator(config)

# Example theorem and proofs
theorem = {
    'statement': 'For all real numbers x and y, if x > 0 and y > 0, then xy > 0',
    'domain': 'algebra',
    'difficulty': 2,
    'prerequisites': ['real numbers', 'multiplication']
}

generated_proof = """
1. Let x and y be positive real numbers
2. By definition, x > 0 and y > 0
3. By properties of positive numbers, their product is positive
4. Therefore, xy > 0
"""

reference_proof = """
1. Assume x > 0 and y > 0
2. In the real number system, the product of positive numbers is positive
3. Thus, xy > 0
"""

# Evaluate single proof with detailed metrics
results = evaluator.evaluate_proof(generated_proof, reference_proof, theorem)

# Print comprehensive results
print("\nEvaluation Results:")
print(f"BLEU Score: {results['bleu_score']:.4f}")
print("\nROUGE Scores:")
for rouge_type, score in results['rouge_scores'].items():
    print(f"{rouge_type}: {score:.4f}")
print(f"\nCorrectness Score: {results['correctness_score']:.4f}")
print(f"Style Score: {results['style_score']:.4f}")

# Print step-by-step analysis
print("\nStep Analysis:")
for step_num, step in enumerate(results['step_analysis'], 1):
    print(f"\nStep {step_num}:")
    print(f"Valid: {step['valid']}")
    print(f"Clarity: {step['clarity_score']:.4f}")
    if step['suggestions']:
        print("Suggestions:", step['suggestions'])
```

### Batch Evaluation with Domain-Specific Analysis

```python
# Prepare batch of proofs
theorems = [
    {
        'statement': 'The sum of two continuous functions is continuous',
        'domain': 'analysis',
        'difficulty': 3
    },
    {
        'statement': 'If a|b and b|c, then a|c',
        'domain': 'number_theory',
        'difficulty': 2
    }
]

generated_proofs = [
    "Let f and g be continuous functions...",
    "Let a, b, c be integers where a|b and b|c..."
]

reference_proofs = [
    "Consider two continuous functions f and g...",
    "Given integers a, b, c with a|b and b|c..."
]

# Calculate batch metrics with domain-specific evaluation
metrics = evaluator.calculate_metrics(
    generated_proofs,
    reference_proofs,
    theorems,
    include_domain_metrics=True
)

# Print domain-specific analysis
print("\nDomain-Specific Analysis:")
for domain, domain_metrics in metrics['domain_metrics'].items():
    print(f"\n{domain.capitalize()} Domain:")
    print(f"Average Correctness: {domain_metrics['avg_correctness']:.4f}")
    print(f"Concept Coverage: {domain_metrics['concept_coverage']:.4f}")
    print("Common Errors:", domain_metrics['common_errors'])

# Generate performance summary
print("\nOverall Performance:")
print(f"Average BLEU: {metrics['avg_bleu']:.4f}")
print(f"Average ROUGE-L: {metrics['avg_rouge_l']:.4f}")
print(f"Correctness Rate: {metrics['correctness_rate']:.4f}")
```

### Comprehensive Error Analysis

```python
# Analyze proof errors with detailed feedback
errors = evaluator.analyze_errors(
    generated_proof,
    theorem,
    provide_suggestions=True,
    check_prerequisites=True
)

# Print structured error analysis
print("\nError Analysis:")
for error in errors:
    print(f"\nError Type: {error['type']}")
    print(f"Location: Line {error['line_number']}")
    print(f"Description: {error['description']}")
    print("Context:", error['context'])
    print("Severity:", error['severity'])
    
    if error['suggestions']:
        print("\nSuggested Fixes:")
        for suggestion in error['suggestions']:
            print(f"- {suggestion}")
    
    if error['related_concepts']:
        print("\nRelated Concepts:")
        for concept in error['related_concepts']:
            print(f"- {concept}")

# Generate improvement recommendations
recommendations = evaluator.generate_recommendations(errors)
print("\nImprovement Recommendations:")
for category, items in recommendations.items():
    print(f"\n{category}:")
    for item in items:
        print(f"- {item}")
```

### Interactive Evaluation Session

```python
# Set up interactive evaluation session
session = evaluator.create_session(
    theorem,
    generated_proof,
    reference_proof,
    mode='interactive'
)

# Step through proof with detailed analysis
while session.has_next_step():
    step = session.next_step()
    
    print(f"\nAnalyzing Step: {step['content']}")
    
    # Verify logical correctness
    logical_analysis = session.verify_logic(step)
    print("\nLogical Analysis:")
    print(f"Valid: {logical_analysis['valid']}")
    print(f"Confidence: {logical_analysis['confidence']:.4f}")
    
    # Check mathematical correctness
    math_analysis = session.verify_mathematics(step)
    print("\nMathematical Analysis:")
    print(f"Valid: {math_analysis['valid']}")
    if math_analysis['assumptions']:
        print("Assumptions Used:", math_analysis['assumptions'])
    
    # Analyze style and clarity
    style_analysis = session.analyze_style(step)
    print("\nStyle Analysis:")
    print(f"Clarity Score: {style_analysis['clarity']:.4f}")
    print(f"Conciseness Score: {style_analysis['conciseness']:.4f}")
    
    # Get step-specific suggestions
    suggestions = session.get_suggestions(step)
    if suggestions:
        print("\nSuggestions for Improvement:")
        for suggestion in suggestions:
            print(f"- {suggestion}")

# Generate session summary
summary = session.generate_summary()
print("\nEvaluation Session Summary:")
print(f"Total Steps: {summary['total_steps']}")
print(f"Valid Steps: {summary['valid_steps']}")
print(f"Overall Quality Score: {summary['quality_score']:.4f}")
print("\nKey Findings:", summary['key_findings'])
```

## Configuration

Detailed configuration options for the evaluation module:

### Metrics Configuration

```yaml
metrics:
  # Text similarity metrics
  text_similarity:
    bleu:
      enabled: true
      weights: [0.25, 0.25, 0.25, 0.25]  # N-gram weights
      smoothing: true
    
    rouge:
      enabled: true
      metrics: ["rouge-1", "rouge-2", "rouge-l"]  # ROUGE variants to compute
      use_stemming: true
      remove_stopwords: true
  
  # Proof quality metrics
  proof_quality:
    correctness:
      enabled: true
      check_premises: true
      check_conclusions: true
      verify_steps: true
    
    style:
      enabled: true
      check_clarity: true
      check_conciseness: true
      check_structure: true
  
  # Domain-specific metrics
  domain_metrics:
    algebra:
      check_equation_manipulation: true
      check_variable_handling: true
      check_term_simplification: true
    
    analysis:
      check_limit_arguments: true
      check_epsilon_delta: true
      check_series_convergence: true
```
